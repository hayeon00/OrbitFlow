# 출장비 정산 매뉴얼

## 1. 정산 양식
출장비 정산은 전자결재 양식 코드 FIN-07(출장비 정산서)을 사용합니다.

## 2. 국내 출장 숙박비
국내 출장 숙박비는 1박당 10만원을 상한으로 실비 지급합니다.
서울 및 제주 지역은 1박당 13만원까지 인정합니다.
해외 출장의 숙박비는 이 매뉴얼이 아닌 해외출장 규정을 따릅니다.

## 3. 직급별 일비 (국내)
| 직급 | 일비(1일) |
| 사원 | 25,000원 |
| 대리 | 30,000원 |
| 과장 | 35,000원 |
| 차장 이상 | 40,000원 |

## 4. 영수증 제출
영수증은 출장 종료일로부터 30일 이내에 제출해야 합니다.
기한 내 제출하지 않으면 해당 비용은 지급되지 않습니다.
단, 부서장이 지연 사유서를 승인한 경우 출장 종료일로부터 60일까지 제출할 수 있습니다.
